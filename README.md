# 🚗 RentalCar

A modern car rental web application built with Next.js and TypeScript.

## 🌐 Live Demo

https://rental-car-teal-omega.vercel.app/

## ✨ Features

- Car catalog
- Car search and filtering
- Detailed car pages
- Rental booking form
- Dynamic routing
- API integration
- Responsive design
- Form validation
- 404 handling

## 🛠 Tech Stack

- Next.js
- React
- TypeScript
- Axios
- CSS Modules
- REST API
- Vercel

## 📱 Responsive Design

The application is optimized for:
- Desktop
- Tablet
- Mobile
