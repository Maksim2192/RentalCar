# 📌 Project Case Study

## 1. Context

RentalCar is a web application designed to simplify the process of finding and booking rental cars. The project was developed as a learning project to gain practical experience in modern frontend development and API integration.

**My role:** Front-end Developer.

**My contribution:** Development of the user interface, React components, TypeScript data structures, API integration, and responsive layouts, according to the tasks I personally completed.

## 2. Problem

Users need a convenient way to browse available cars, find suitable options, review vehicle details, and submit rental requests.

The main technical challenges included:
- Organizing a clear and user-friendly car catalog.
- Fetching and displaying data from a REST API.
- Implementing search and filtering functionality.
- Creating dynamic pages for individual cars.
- Validating user input in the rental form.
- Handling loading states, errors, and unavailable pages.
- Adapting the interface to different screen sizes.

## 3. Approach

The project uses a modern frontend stack selected for component reusability, type safety, and maintainability.

- **Next.js and React** — building the interface and organizing application pages.
- **TypeScript** — improving code reliability through static typing.
- **Axios** — sending HTTP requests to the API.
- **CSS Modules** — styling components with locally scoped CSS.
- **REST API** — retrieving and displaying car data.
- **GitHub** — version control and source code hosting.
- **Vercel** — deploying the application.

## 4. Execution

The development process included the following stages:

1. **Project structure:** Organized application pages and reusable components.
2. **UI development:** Built the car catalog and individual car detail pages.
3. **API integration:** Connected the frontend to the REST API using Axios.
4. **Interactive functionality:** Implemented car search, filtering, dynamic routing, and the rental request form.
5. **Validation and error handling:** Added input validation and handling for unavailable pages and missing car data.
6. **Deployment:** Published the application on Vercel and made the source code available on GitHub.

## 5. Result

The project resulted in a deployed car rental web application with a responsive interface and API integration.

Key outcomes:
- Developed the frontend using Next.js, React, and TypeScript.
- Implemented a car catalog and detailed vehicle pages.
- Integrated the application with a REST API.
- Added search, filtering, and rental form functionality.
- Implemented responsive layouts and error handling.
- Published a live demo for portfolio presentation.

## 6. Takeaways

This project helped me strengthen my practical skills in React, Next.js, TypeScript, API integration, and responsive web development.

I also gained experience organizing reusable components, working with dynamic data, and handling common frontend errors.

**Potential improvements:**
- Add automated tests for key user flows.
- Measure and optimize page performance.
- Improve accessibility.
- Expand car filtering options.
- Add analytics to evaluate user interactions.
